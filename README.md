# Wiki: suspensión de la ejecución de la pena

Este sitio es una página estática en español sobre la suspensión condicional de la ejecución de la pena de prisión en Honduras. El contenido está en `index.html` y no requiere dependencias ni compilación.

## Publicar gratis con GitHub Pages

1. Crea un repositorio **público** en GitHub. Por ejemplo, `wiki-suspension-pena`.
2. Sube `index.html` a la raíz del repositorio. Puedes subir también este `README.md`.
3. En el repositorio, abre **Settings → Pages**.
4. En **Build and deployment**, selecciona **Deploy from a branch**, elige `main` y la carpeta `/(root)`, y guarda.
5. Espera a que termine la publicación. GitHub mostrará el enlace público en la misma sección de Pages; normalmente tendrá el formato `https://USUARIO.github.io/wiki-suspension-pena/`.

El repositorio debe ser público para que la página pueda consultarse públicamente con GitHub Pages en el plan gratuito. Quien tenga el enlace podrá leer la página; esto no permite que cualquier visitante edite el repositorio. Para habilitar ediciones colaborativas, hay que gestionar aparte los permisos del repositorio.

## Actualización del contenido

El texto legal puede cambiar. Antes de publicar o actualizar el artículo, verifica las reformas en la [Biblioteca Virtual del Tribunal Superior de Cuentas](https://www.tsc.gob.hn/biblioteca/index.php/codigos/830-codigo-penal-2019) y revisa el alcance de la página en la nota informativa incluida en `index.html`.
